## 🎯 The Mission
Our oceans are vast, under-monitored, and facing unprecedented threats. **REEF** serves as the ultimate tactical dashboard for marine biologists and conservationists. By unifying telemetry from deep-sea drones, live sonar arrays, and biodiversity tracking systems, REEF empowers teams to secure the future of our oceans before it's too late.

---

## ✨ The Dashboard (A Living Interface)

This isn't just a static template; it's a living, breathing ecosystem. We've engineered a custom **Live Simulation Engine** using React Context that injects real-time ticking data directly into the UI, giving you a true "Mission Control" experience.

### 🚀 Key Features 

- ⏱️ **Live Telemetry Simulation:** Watch API calls surge and drone batteries dynamically drain in real-time as the simulation runs.
- 🌍 **Global MapLibre Integration:** Navigate real-world satellite imagery mapped with high-performance WebGL, featuring active threat pulse-markers deep within the Mariana Trench.
- 💎 **Glassmorphism Design System:** Built from the ground up using custom Tailwind configurations to achieve a deep-sea, glowing, cyber-tactical aesthetic.
- ⚡ **Seamless React Router Architecture:** Fluid page transitions utilizing Framer Motion for buttery-smooth, application-like routing without any reloads.
- 📱 **Fully Responsive:** Perfectly scaled for both 4K mission control monitors and rugged tablet field devices.

## 🚀 Quick Start (Local Setup)

To spin up the REEF Deepsea Guardian command center on your local terminal and view the live simulation:

```bash
# 1. Clone the repository
git clone https://github.com/Prajitsingh1105/reef-hackocean.git


# 2. Install dependencies
npm install

# 3. Start the simulation environment
npm run dev
```

*Navigate to `http://localhost:5173` in your browser to enter Mission Control.*
